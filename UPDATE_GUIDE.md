# Руководство по обновлению (Docker)

Чтобы обновить приложение на сервере с новыми изменениями, выполните следующие действия:

### 1. Получите последние изменения кода
Зайдите на сервер через SSH и перейдите в папку проекта:

```bash
cd /path/to/ai-uz-lawyer  # Замените на ваш путь
git pull origin main
```

### 2. Пересоберите контейнеры
Так как мы изменили структуру папок (переименовали папку с контрактами), лучше всего пересобрать контейнер бэкенда:

```bash
docker-compose build backend
```

### 3. Перезапустите приложение
```bash
docker-compose up -d
```

### 4. Проверка
После перезапуска, зайдите на страницу генератора. Вы должны увидеть категорию **"Гражданско-правовой (ГПХ) договор"** в списке. При выборе этой категории она должна успешно работать (не вызывать ошибок).

> **Примечание:** Если вы не используете `git` на сервере, а копируете файлы вручную, убедитесь, что вы удалили старую папку `contracts/Гражданско-правовой (ГПХ) договора` и загрузили новую `contracts/gph_contract`.
